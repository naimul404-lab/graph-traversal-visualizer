# Graph Traversal Visualizer

An interactive project for visualizing graph algorithms and understanding traversal patterns in a simple, visual way.

## Features

- BFS traversal visualization
- DFS traversal visualization
- Shortest-path concept demonstration using Dijkstra-inspired logic
- Random graph generation
- Adjustable node count and speed
- Clear algorithm information panel

## Why this project matters

Graph algorithms are essential in computer science. This project demonstrates algorithmic reasoning and helps users understand how traversal and shortest-path logic work in practice.

## Run locally

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
